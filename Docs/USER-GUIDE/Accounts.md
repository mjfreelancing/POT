# Account Management

## Overview

Accounts are the foundation of projections and dashboard totals. Each account holds your current balance, reserved amount, and accrual-based totals used to determine what is truly available to spend.

## Available to

- Site Owners (full access)
- Admins (full access)
- Viewers (view only)

## Key Features

- Create, edit, and delete financial accounts
- Track balance and reserved funds
- Review the accrued, arrears and committed totals used by availability calculations
- Sortable columns for Balance, Reserved, Available, Daily Need, Accrued, Arrears and Committed

### Key Concepts

- Balance: current account amount.
- Reserved: protected amount you do not want to spend.
- Accrued: amount set aside for the expense cycles currently in progress.
- Arrears: amount owed for expense cycles whose due date has already passed without being settled.
- Committed: accrued plus arrears — what the account balance is committed to cover.
- Available balance: amount left after the reserved and committed amounts are accounted for.
- Daily Need: stable daily set-aside requirement derived from active obligations.
- A bill due today is the current bill: it counts as accrued and is not arrears.

## Column Hints

Hover any column heading to see a hint describing what that column shows. The hints cover the same
definitions listed under Key Concepts.

## Step-by-Step Guide

1. Create an account with description, balance, and optional reserved amount.
2. Keep balance current as statements or transactions change.
3. Add expenses and income linked to the account.
4. Read the Accrued, Arrears and Committed columns to see what the balance is committed to.
5. Use account totals and dashboard Daily Need to guide spending decisions.

## Permission-Based Features

### For All Users

- View account list, balances, and totals

### For Site Owners & Admins

- Create, edit, delete accounts

### For Viewers

- Read-only visibility of account state and totals

## Tips & Best Practices

- Keep balances current to improve projection realism.
- Use reserved funds for non-discretionary buffers.
- Treat Daily Need as a planning cadence, and Available as spend-control guidance.
