# POT User Guide

This guide provides detailed instructions for using each feature in POT (Pay On Time).

Each page includes step-by-step instructions and explains how features vary based on your permissions (Site Owner, Admin, or Viewer).

## Main Features

- [Dashboard](Dashboard.md) - Your financial command center
- [Projections](Projections.md) - View future account balances
- [Expenses](Expenses.md) - Manage bills and payments
- [Income](Income.md) - Track income sources
- [Accounts](Accounts.md) - Manage financial accounts
- [Export](Export.md) - Export your financial data
- [Import](Import.md) - Import financial data
- [Settings](Settings.md) - Customize your POT experience

## User Management

- [Users](Users.md) - Invite and manage users (Site Owners & Admins)
- [Approvals](Approvals.md) - Approve new users (Platform Admins)

## Permissions Overview

POT uses role-based permissions to control access:

- **Site Owner** - Full control over site, users, and all financial data
- **Admin** - Can manage financial data and invite users
- **Viewer** - Can view financial data but cannot modify

Platform Admins have special `platform:manage` permission for cross-site administration.
